# Security policy

Report suspected vulnerabilities privately through GitHub Security Advisories
for this repository. Do not open a public issue with exploit details, secrets,
or production endpoint evidence.

Include affected versions or commits, a minimal reproduction, impact, and any
suggested mitigation. The maintainer will acknowledge reports, establish a
private remediation plan, and coordinate disclosure after a fix is available.

Do not use production credentials or destructive requests while validating a
report. MakerBench treats server-side URL fetching, authentication, RLS, rate
limits, secret handling, and dependency changes as security-sensitive.
